## 2. Contradictions and ambiguities and their resolutions

| ID  | Where                                                                                                                           | Issue                                                                                                                        | Resolution                                                                                             | Bricks       |
| --- | ------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ------------ |
| C1  | Spec interface vs Lua section                                                                                                   | `Check(key, cost, now)` takes a client `now`, but the spec also says use Redis `TIME` to avoid client skew                   | Redis-backed `Check(ctx, key, cost)` has no `now`; only the Go local limiter has an injectable `Clock` | 3.3, 5.2, T2 |
| C2  | Spec keys: `rl:{ruleId}:{dimensionValue}` vs `{user123}`; old guide `{rl:rule:user123}`; old tasks `rl:{rule_id:dimension_val}` | Three formats; the spec's first form tags only the rule id, putting every subject of a rule on one slot                      | `rl:{<ruleId>:<dimValue>}[:suffix]`; tag wraps rule id and dimension value; ADR 002                    | 4.1, 8.2     |
| C3  | Spec "apply all, deny if any" vs old tasks "API Key > User ID > IP"                                                             | Two different precedence models                                                                                              | MVP = apply-all per spec; hierarchy is stretch                                                         | 4.2, 4.3     |
| C4  | Multi-rule vs Cluster                                                                                                           | Rules on different slots cannot be one atomic script; tokens consumed by allowing rules are not refunded when another denies | Accept and document (ADR 003); check-then-consume is stretch                                           | 4.3          |
| C5  | Old tasks "P50 < 1ms, P99 < 3ms"                                                                                                | Targets not in the spec; spec only requires a P50/P99 benchmark                                                              | Treated as hypotheses; criterion is a recorded measurement with method                                 | 9.2          |
| C6  | Spec "throughput grows with shards"                                                                                             | One host's CPU bounds a local cluster                                                                                        | Run as stretch; label single-host and do not extrapolate                                               | 8.3          |
| C7  | Spec "hot-reload: watch for changes" vs old tasks                                                                               | Old tasks had only manual `Reload()`                                                                                         | Added file-watch brick                                                                                 | 1.6          |
| C8  | Spec Lua `EVALSHA` vs Cluster                                                                                                   | Script cache is per node; `SCRIPT LOAD` on one node is not enough (verify with go-redis behaviour)                           | Load on every master; test after node restart                                                          | 3.2, 8.2     |
| C9  | Old TASKS dashboard vs detail                                                                                                   | Phase 3 and Phase 6 named differently; Phase 6 location link inconsistent                                                    | Names and paths unified                                                                                | -            |
| C10 | Spec "Express/Nest guard or Go `http.Handler`"                                                                                  | Choice left open                                                                                                             | Go `http.Handler` for MVP; NestJS guard stretch                                                        | 6.3          |
| C11 | Old guide "NEVER write core code"                                                                                               | Absolute rule leaves no path for first-time constructs or boilerplate                                                        | Tiers A/B/C/W with worked examples in `sandbox/`                                                       | guide s3     |
