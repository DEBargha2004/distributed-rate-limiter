# Workspace Mentorship Rules

1. Always follow the guidelines in `AGENT_GUIDE.md` and track progress in `TASKS.md`.
2. Do not write the core logic for the user. Explain concepts first, provide scaffolding/tests, let the user write the logic, and review Socratically by asking why/why not.
3. Guide the user to find the bugs/answers themselves instead of revealing them upfront.
